# 腾讯代码安全基线

中文规则源 | [English](../en/tencent-security.md) | 配对修订：`2026-10-05.9`

安全指南来源采用 [Tencent/secguide](https://github.com/Tencent/secguide)。以下为面向大模型开发重新组织的适用性检查，并非腾讯原文，也不是已完成的安全审计。腾讯资料按 CC BY 4.0 发布；本文件增加了风险路由、测试要求和旧样例限制。

## 使用方式

只检查本次改动及其直接输入输出/调用边界。先识别不可信输入、执行/存储/渲染位置、身份权限、敏感数据，再选下面适用的要求。不涉及的项目标记不适用，不凭工具调用次数宣布“安全通过”。

原仓库 README 的修订日期为 2021-05-18。不得把历史运行版本、密码策略或样例中的简易过滤函数当作今天的通用安全保证；具体实现必须结合项目版本、可信库和当前官方说明核对。

## 通用安全要求

| 触发点 | 必须达到的结果 | 有针对性的验证 |
| --- | --- | --- |
| 外部输入 | 在信任边界验证类型、范围、长度和结构；拒绝不合法输入 | 空值、超长、错误类型、边界值 |
| 身份与权限 | 服务端鉴权；按操作和资源/租户验证授权，默认不放行 | 未登录、无权用户、跨用户/跨租户访问 |
| 数据库 | 查询值参数化；动态标识符使用受控映射；ORM 的原始查询同样检查 | 注入输入不能改变查询结构；合法特殊字符仍正确 |
| 系统命令/执行 | 优先库 API；必要时固定程序、参数数组、受控选项和资源限制 | 元字符、前导选项、错误程序、超时/取消 |
| 文件/上传/解压 | 验证实际目标在允许目录，限制类型/大小与资源消耗；不可成为可执行文件入口 | 绝对路径、穿越、同名前缀目录、符号链接与压缩包条目 |
| 外部 URL/下载 | 按业务约束协议和目的地，考虑解析地址、重定向及网络访问边界 | 非允许协议/地址、重定向到禁止目标、资源上限 |
| 页面/模板 | 按输出上下文安全渲染；富文本使用成熟清理组件；不执行不可信文本 | HTML/脚本/属性/URL 注入输入 |
| 序列化/XML | 不从不可信数据恢复可执行对象；按需求关闭危险实体和外部资源解析 | 恶意序列化/实体输入被拒绝或安全解析 |
| 密钥/敏感数据 | 密钥不入源码/前端/日志；最小化返回字段、服务器脱敏；密码使用专用安全存储机制 | 检查差异、日志和错误响应，不输出真实秘密 |
| 通信/加密 | 不以关闭 TLS 验证解决连接问题；使用经过维护的密码学组件和合适密钥管理 | 验证错误证书/配置失败不会被静默放行 |
| 资源与并发 | 控制大小、超时、并发和生命周期；错误不导致泄漏或无限重试 | 超大/截断输入、竞争、取消、重复调用 |
| 错误/配置/依赖 | 对外错误不泄漏内部信息；生产不启用调试后门；新增依赖核对来源和已知风险 | 错误响应、生产配置、锁文件及现有扫描结果 |

验证用本地合成数据和隔离测试，不主动扫描公网、探测生产内网或使用真实凭证。

## 语言入口

- **Python**：[腾讯 Python 指南](https://github.com/Tencent/secguide/blob/main/Python%E5%AE%89%E5%85%A8%E6%8C%87%E5%8D%97.md)。重点检查 SQL、子进程、路径、外部 URL、危险 YAML/对象反序列化、XML 和生产调试配置。
- **Java**：[腾讯 Java 指南](https://github.com/Tencent/secguide/blob/main/Java%E5%AE%89%E5%85%A8%E6%8C%87%E5%8D%97.md)。重点检查注入、文件/网络输入、敏感信息与业务访问边界；按实际框架核对相关功能。
- **JavaScript / TypeScript / Node.js**：[腾讯 JavaScript 指南](https://github.com/Tencent/secguide/blob/main/JavaScript%E5%AE%89%E5%85%A8%E6%8C%87%E5%8D%97.md)。重点检查 DOM/HTML 插入、动态执行、URL、`postMessage` 来源、子进程、查询、Cookie 和敏感配置。
- **Go**：[腾讯 Go 指南](https://github.com/Tencent/secguide/blob/main/Go%E5%AE%89%E5%85%A8%E6%8C%87%E5%8D%97.md)。重点检查外部长度/索引、命令/路径、查询、TLS、共享状态和协程退出。
- **C / C++**：[腾讯 C/C++ 指南](https://github.com/Tencent/secguide/blob/main/C%2CC%2B%2B%E5%AE%89%E5%85%A8%E6%8C%87%E5%8D%97.md)。重点检查边界、长度/整数转换、内存生命周期、格式串、系统接口和敏感信息。
- 其他语言沿用通用目标，再查实际语言/框架的官方安全 API；不能假称腾讯已提供对应专用指南。

遇到具体高风险 API 且本地证据不足时，读取对应原文相关部分和当前 API 文档；无需每次加载全部语言手册。

## 不能照搬的旧样例

以下限制是本 Skill 的工程修订，不冒充腾讯原始条款：

- SQL 删除危险字符的黑名单不能代替参数绑定；数据校验和查询结构安全是不同检查。
- Shell 字符替换不能保证命令安全。参数数组也要防目标程序的选项注入；不要包一层 `sh -c` 再拼入外部输入。
- 路径中不包含 `..` 或字符串前缀相同，不等于目标在允许目录。使用路径组件/目录边界检查，并按威胁模型处理符号链接和检查/使用竞态。
- SHA-2 是摘要算法，不是可恢复数据的加密方式；通用快速哈希也不应直接当作密码存储方案。不自造算法或参数。
- 旧版运行时、组件名或样例依赖不作为版本下限；查项目支持范围和当前维护状态。
- 日志保留期、密码长度、企业域名、文件命名长度等应按业务/合规和当前策略确定，不硬编码腾讯业务环境。

遇到已有的相关不安全实现，说明证据和修复范围；不能为了满足这份基线重写无关模块。无法满足本次安全目标时报告阻塞，不声称已安全完成。
